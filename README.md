The LaTex source code for my book. Please read the PDF file. Thank you very much!

# Installation
This requires the following packages
- texlive-bibtexextra
- texlive-latexrecommended
- texlive-pictures
- textlive-nicematrix
- bibtex
- biber
- latexmk

# Make
```sh
latexmk -pvc -pdf -interaction=nonstopmode sasquare.tex
```
